Skills are Markdown files today. The lowest-friction enterprise pattern should not ask teams to abandon that.

**Skills as Code** treats Markdown as the authoring format. A compiler reads ordinary `SKILL.md` files, verifies required and final sections, and vendors clean `SKILL.md` output for the agent.

<div class="statement-panel">
  <p><strong>MVP scope:</strong> plain <code>SKILL.md</code> only. No Kustomize, YAML resource schema, templates, AIBOM/run BOM, or build-script model in this version.</p>
</div>

## One-Minute Story

Organization protects the security review. Team fills Jira project `PAY`. Repository adds local context. The agent receives clean `SKILL.md`.

<div class="hero-flow" aria-hidden="true">
  <div class="flow-node flow-base"><span>organization</span><strong>base SKILL.md</strong></div>

## Who Writes What

The MVP composes three Markdown sources:

<CardGrid>
  <Card title="1. Organization">
    Publishes the base SDLC skill, required sections, and final security review.
  </Card>
  <Card title="2. Team">
    Supplies the Jira project context and team implementation guidance.
  </Card>
  <Card title="3. Repository">
    Supplies local ownership and verification context.
  </Card>
  <Card title="Vendored Output">
    The generated file is checked in for the agent to load. Do not edit it directly.
  </Card>
</CardGrid>

## Small Example

The organization marks sections that must be completed later:

```md
# /org/skills/sdlc/SKILL.md
## Jira Project Context <!-- @required -->

<!-- Team must declare the Jira project key. -->

## Security Review <!-- @final -->

Review authentication, authorization, injection, secrets, and sensitive data risks.
```

The team fills its owned section:

```md
# /teams/payments/skills/sdlc/SKILL.md
## Jira Project Context

Use Jira project `PAY`.
```

The repository declares the expected composition:

```yaml
# /repos/payments-api/skills.yaml
skills:
  enterprise-sdlc:
    sources:
      - github.com/acme/skills/org/sdlc/SKILL.md@v1.2.0
      - github.com/acme/skills/teams/payments/sdlc/SKILL.md@v0.8.0
      - .skills-src/sdlc/SKILL.md
    output: .claude/skills/sdlc/SKILL.md
```

The compiled result is ordinary Markdown with annotations stripped:

```md
# /repos/payments-api/.claude/skills/sdlc/SKILL.md
## Jira Project Context

Use Jira project `PAY`.

## Security Review

Review authentication, authorization, injection, secrets, and sensitive data risks.
```

## What Matters

- Authors keep writing Markdown.
- Required sections make the base skill intentionally incomplete until local prose exists.
- Final sections protect organization-owned instructions from downstream edits.
- Vendored output makes review and CI drift detection concrete.
